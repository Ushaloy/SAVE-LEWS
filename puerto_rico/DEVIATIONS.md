# Deviations from PREREGISTRATION.md

- 2026-09-27 01:40 (+07): Cross-validation changed from leave-one-storm-out to leave-one-block-out (contiguous blocks of ~9 storms; Utuado 10 blocks, Toro Negro 8 blocks) with the same ±24 h purge around every held-out window. Reason: solver calibration costs ~7 min per fold, so 140 LOSO folds were infeasible. Decided before any model skill was computed. The change is conservative (smaller training sets) and is applied identically to all models.
- Input gaps: the shallow input is interpolated to drive the solver; rows whose input was interpolated are excluded from scoring, as registered. Windows with <80% shallow input are dropped.
- R-lab uses the lab drying curve of the sample closest to the primary target (Utuado z=0.35 m sample = 0.57 m depth; Toro Negro ELT z=0.42 m sample = 0.90 m depth); lab θr = 0.10 is clipped to the solver's bound of 0.08.
- 2026-09-27 02:05 (+07): Added EXPLORATORY model R-cal-Se (not in the registration). Trigger: training-set fits only (no held-out skill seen) — Utuado R-cal block 0 pinned α, θs and θr at their bounds with train RMSE 0.042; Toro Negro R-cal did not move from its start because the 30 cm probe reads above the model θs, saturating the column. Cause: sensors at different depths read different θ ranges (sensor calibration and texture), which a homogeneous θ-based model cannot represent. R-cal-Se normalises each sensor to effective saturation using its own training-window 0.5–99.5% range and calibrates Ks, α, n only. R-cal remains the registered test; R-cal-Se is reported as exploratory and cannot by itself support P1.
- 2026-09-27 02:40 (+07): Bug fix, not a design change. Gradients of the van Genuchten functions were NaN at saturated nodes (the jnp.where gradient trap), which froze Levenberg–Marquardt at its starting point at Toro Negro and may have degraded Utuado fits. Fixed by evaluating the unsaturated branch at a safe negative head; forward solutions unchanged (train RMSE 0.02099 → 0.02097 on a test fold). All physics runs were discarded and rerun; no held-out skill had been computed.
- 2026-09-27 02:55 (+07): P4 implementation fixed before any held-out skill or coverage was computed. Posterior = Laplace (Gauss–Newton) approximation around each fold's calibrated parameters, covariance σ²(JᵀJ)⁻¹ on the training residuals; observation noise Gaussian with σ estimated on training windows in elapsed-time bins (0–6, 6–24, 24–48, >48 h since window start); 200 posterior-predictive draws per held-out window. Baseline: PG-MLP seed 0 with cross-conformal intervals (other blocks' held-out residuals, same elapsed-time bins). Applied to R-cal (registered) and, as exploratory, R-cal-Se. NUTS was not used because one gradient through the solver costs ~20 s.
- 2026-09-27 06:05 (+07): Second bug fix, not a design change. The solver clipped pressure head at −1e5 cm; for the fitted parameters, dry initial states require more negative heads, so the clip silently raised dry nodes' water content (e.g., 57 cm initial 0.070 → 0.102) and suppressed deep responses. Found by inspecting an example storm plot after the first P1 scoring. Clip widened to −1e9 cm; convergence unchanged. All physics (R-cal, R-cal-Se, R-lab) and P4 runs discarded and rerun; the P1 scores computed before this fix are superseded and not reported as results. PG-MLP runs are unaffected (no solver).
